# Songie - Audio Sharing Website

A web application for sharing audio files with friends. Built with Next.js, featuring upload, tagging, rating, browsing, waveform visualization, and commenting.

## Features

- Bulk upload audio files with instrument, vibe, and ratings
- Browse and sort files by instrument and vibe
- Play audio in-browser with seeking
- Waveform visualization to see audio levels
- Rate and tag files
- Comment on files

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Project Structure

- `app/` - Next.js app directory
  - `api/` - API routes for upload and file management
  - `upload/` - Upload page
  - `browse/` - Browse files page
  - `player/[id]/` - Audio player page
- `public/uploads/` - Stored audio files
- `public/data.json` - File metadata

## Technologies

- Next.js
- React
- Tailwind CSS
- WaveSurfer.js
- React Dropzone
